# Genomic Repeats

This folder contains the genomic repeat analysis used to investigate regional patterns of **CpG suppression and TpG enrichment** in human rhinovirus (HRV).

## Folder Structure

* **`genbank_files/`** — GenBank files containing the HRV genomic sequences used for the analysis.
* **`CpG Motif Detection.R`** — Exploratory analysis used to investigate CpG motif patterns and inform the final analysis.
* **`genomic_repeats.Rmd`** — Main analysis file. Contains the code used to generate the analyses and figures reported in the final project.
